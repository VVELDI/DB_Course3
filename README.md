# Проект: Парсер вакансий с HeadHunter

Этот проект предназначен для сбора и анализа вакансий с сайта HeadHunter (hh.ru). Он позволяет:
1. Получать данные о вакансиях через API HeadHunter.
2. Сохранять данные в базу данных PostgreSQL.
3. Выполнять поиск и фильтрацию вакансий.
4. Сохранять результаты в JSON-файл.

## Структура проекта

project/ 

│  
├── src/ # Папка с исходным кодом  
│ ├── api_module.py # Модуль для работы с API HeadHunter  
│ ├── DB_Create_module.py # Модуль для работы с базой данных  
│ ├── DB_manager_module.py # Модуль для управления базой данных  
│ ├── files_module.py # Модуль для работы с файлами (сохранение в JSON) 
│ └── vacancy.py # Модуль для работы с объектами вакансий  
│  
├── tests/ # Папка с тестами  
│ ├── test_api_module.py  
│ ├── test_DB_Create_module.py  
│ ├── test_DB_manager_module.py  
│ ├── test_files_module.py  
│ └── test_vacancy.py  
│  
├── data/ # Папка с данными  
│ └── vacancies.json # JSON-файл с вакансиями  
│  
├── main.py # Главный скрипт для запуска программы  
├── README.md # Документация проекта  
└── pyproject.toml # Зависимости проекта

1. **Клонируйте репозиторий:**
   ```bash

   cd ваш-репозиторий
   
2. **Настройте базу данных:**

```Установите PostgreSQL и создайте базу данных.```

3. **Создайте файл .env в корне проекта и добавьте в него следующие переменные:**

```

USERNAME=ваш-пользователь  
PORT=ваш-порт  
PASSWORD=ваш-пароль
```
  
4. **Запустите проект:**

Для запуска программы выполните:

```bash
python main.py
